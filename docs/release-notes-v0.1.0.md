# IFZ Cheat Panel v0.1.0

《无感染区》(Infection Free Zone) 的游戏内 F7 控制台面板。首个公开发布版本。

## 安装

1. 先安装 **BepInEx 5.4.23+ (x64)** 到游戏根目录
   - 装好后游戏目录应该出现 `winhttp.dll` 和 `BepInEx\core` 文件夹
2. 下载本 Release 里的 `IfzCheat.dll`
3. 放到 `<游戏目录>\BepInEx\plugins\IfzCheat.dll`
4. 启动游戏 → 读档 → 按 **F7**

## 功能

- **F7 呼出面板**，窗口可拖动、实心亮色底板
- **命令自动发现**：反射扫描 `Commands.GameConsoleCommandHandler` 上全部 `[GameCommand]`
  方法（当前游戏版本 178 条），不硬编码命令表
- **全中文**：内置命令中文说明，搜索支持中英混搜
- **一键资源**：木材 / 金属 / 砖块 / 口粮 / 弹药 / 燃料 / 药物 / 基础工具 / 高级工具 /
  电子零件 / 木板 / 罐头 / 蔬菜 / 肉类 / 化肥 / 手雷 / 炸药 / 地雷 / 谷物
- **剧情物品**：疫苗 / 血液样本 / 疾控箱 / 科学材料
- **全部资源各 +500 / +5000**
- **一键开关**：快速建造、快速研究、免费研究、城墙不毁、无限弹药、无饥饿、完美心情、
  完美天气、解锁全内容、解锁全远征、显示巢穴、一键搜刮
- **自由命令输入**：手改参数执行，结果直接显示在面板顶部

## 说明

- 加资源不走控制台命令，而是直接调用总部资源容器的 `ForceAddResource`
  （与游戏自带「一键加资源」同一路径），可绕过容量限制
- 全程反射调用，**不修改、不反编译游戏文件**
- 游戏自带 `TrainerMonitor`，使用后成就/统计可能受影响；剧情道具（疫苗等）刷入
  仓库不一定推进剧情进度，建议先存档

## 兼容性

- 游戏版本：Unity 6 (6000.0.26f1) 对应版本测试通过
- 依赖：BepInEx 5.4.23.2 (win_x64)
- 游戏大更新后若提示「未找到命令处理器」，说明类型改名了，请提 issue
